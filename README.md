# NSTL_test

Neural Semantic Tree Lattice (NSTL) Engine Prototype.
Features a FastAPI + PyWebview runtime with HNSW retrieval (Jina v5 Nano) and Three.js 3D visualization.

## Features
- **Dynamic Resolution Scaling**: Independent of OS scaling settings, scales all font sizes and layout panels based on viewport.
- **Asynchronous Engine Loading**: Instant window startup displaying a real-time bootstrap status log.
- **Mobile Responsive Layout**: Compact tab bar interface and dynamic remote server host config.

## Run Locally
Ensure Python dependencies are installed, then run:
```bash
python main.py
```
